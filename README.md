# Console BMI Calculator in C#

A simple and clean C# Console Application that calculates a user's Body Mass Index (BMI) based on their weight and height, and determines their weight category according to standard medical guidelines.

## Features
- **BMI Calculation:** Computes accurate BMI using standard metric formulas.
- **Category Classification:** Automatically categorizes the result into:
  - Underweight
  - Normal weight
  - Overweight
  - Obesity
- **Interactive Console Input:** Prompts the user to securely input their weight (kg) and height (m).

## Prerequisites
- [.NET SDK 6.0 / 7.0 / 8.0 / 9.0](https://dotnet.microsoft.com/download) (or Visual Studio)
